# 做装模拟参考与实现边界

## 界面与交互参考

用户指定的 [Craft of Exile](https://www.craftofexile.com/?cl=cn) 通货模拟界面：顶部选工艺和通货，左侧展示物品并应用通货，中间按前后缀查看词缀系列与阶级，右侧查看历史、消耗和目标。导入与新建底材放入项目弹窗。

没有把 Craft of Exile 的前端资源视为已获开源许可，没有复制其代码或游戏图像。本站保留现有主题并使用本地组件与 CSS 绘制通货标记。

## 当前实现

当前规则仍由本项目实现，依据项目固定快照中的通货和征兆说明。新增规则支持破裂石以及 15 种征兆：富豪定向前/后缀，崇高定向前/后缀及双词缀，剥离定向前/后缀及双词缀，混沌定向移除前/后缀及按最低需求物等移除，完美精华定向移除，以及亵渎定向添加。

同一通货可组合兼容征兆，例如“右旋崇高 + 强效崇高”添加两条后缀。相反方向和不同移除选择方式不能同时启用。每次操作先在副本上执行，失败不会修改物品或消耗记录。已破裂词缀不会被移除或重骰。目标选择只追踪命中，不改变随机结果；历史回看不会回退真实进度。

### 分阶通货与精华

高阶/完美蜕变及增幅的新词缀最低需求等级为 55 / 70；富豪、崇高及混沌为 35 / 50。过滤只作用于新词缀，保留原词缀。规则参考 pyoe2-craftpath 的 0.4.0 实现；固定快照中的通货说明确认基本动作，但没有注明该最低等级，不能仅凭数据版本标签宣称这些阈值已逐项验证到 0.5.5。

精华对应表来自 [Path of Building 的固定 Essence.lua](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2/blob/bb52d6b368307457eb9c54bb13f1829993d390b1/src/Data/Essence.lua)，该表标注 Item data (c) Grinding Gear Games；项目代码为 MIT。仅导入数据映射，未复制模拟引擎。精华数值和互斥组仍使用本地 RePoE 快照；无法关联的组合不开放。低阶、普通、高阶精华把魔法升为稀有并保留旧词缀；完美精华移除一条可移除词缀，再添加保证词缀。结晶征兆控制移除方向。任何可能的移除结果无法添加保证词缀时，会阻止操作，避免通过失败重试偏置结果。

### 亵渎与腐化的参考模型

亵渎先占用前缀或后缀位置，揭示时从该方向的普通与适用亵渎池中生成最多三个不同词缀系列。先等概率抽取系列，再等概率抽取该系列的合法档位；不声称这是游戏实际权重。方向未指定时在有空位的方向中等概率选择。揭示选项和数值保存在步骤快照，刷新不重骰；选定结果后仍记录其亵渎来源，直到该词缀被移除。揭示与选择免费，亵渎材料及征兆按数量记录。未揭示词缀可被剥离、混沌及完美精华移除，不参与破裂随机选择。未揭示词缀与削磨征兆的等级比较尚未核实，因此阻止该组合。

腐化当前为**用户指定结果分支的推演**，支持无变化、添加腐化附魔、重铸为 4–6 词缀稀有物品，以及支持插槽底材增加一个符文插槽。没有随机选择分支，也不计算其成功率；附魔池和重铸数量暂按等概率模型抽取。词缀仍检查物等、互斥和上限，腐化后禁止继续使用通货，撤销可恢复。破裂物品的腐化重铸未核实，明确阻止。额外插槽只记录增量，尚未重建原物品的完整插槽状态。

路线搜索、市场价格、腐化精华、深渊回响等其他专属征兆、双重腐化及后续神庙工艺尚未实现。导入特殊状态仍采用保守识别；本轮支持的是在工作台内部生成并保存的特殊状态。原始普通生成权重也依赖上游数据，所有概率均不能视为已验证的游戏概率。
